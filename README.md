# 시리우스 영상 리뷰

휴대폰에서 Sirius UT 인터뷰 쇼츠를 보고 **좋음 / 수정 필요 / 제외**로 나누는 정적 페이지입니다. 서버, 로그인, 데이터베이스, 분석 도구는 없습니다.

최신 목록은 대표 15편과 04 햇살 변주 1편, 모두 16편입니다. 04, 05, 06, 08, 10, 11, 13, 14, 15와 04 햇살 편은 목소리만 바꾼 age_voice_v1이고, 그 나이가 맞다는 뜻은 아닙니다. 12편 최신은 목줄이 이어진 컷이고, 그 전 clean_v3는 버전 선택에 남습니다. 나머지 최신은 clean_v3입니다. 04 햇살 편은 **변주**로만 열리며 대표 목록에 섞이지 않습니다. 평가와 메모는 연 브라우저의 `localStorage`에만 남고, 영상 id와 version이 같아야 같은 평가로 이어집니다. clean_v3는 새 version이라 미평가로 시작합니다. 전시(exhibition_v2)와 처음 버전의 평가와 파일은 지우지 않으며, 같은 회차의 버전 선택에서 그대로 볼 수 있습니다. 다른 기기와 자동으로 동기화되지 않습니다.

`README.txt`는 영상·카탈로그를 준비한 입력 설명입니다. 이 파일은 사이트 사용 설명입니다.

## 로컬에서 보기

저장소 루트에서 정적 서버를 띄웁니다.

```bash
python3 -m http.server 8765
```

GitHub Pages 프로젝트 주소와 같이 보려면 상위 폴더에서 `sirius-video-review/`로 이 저장소를 열고 `http://127.0.0.1:8765/sirius-video-review/`로 접속합니다. 스타일, 목록, 영상 주소는 모두 상대 경로입니다.

## 평가 백업

화면 아래 **평가 보내기**가 JSON 파일을 만듭니다. **평가 가져오기**는 형식을 확인한 뒤, 이 브라우저의 평가를 바꾸기 전에 한 번 더 묻습니다. 잘못된 파일은 저장하지 않습니다.

## 음악

음악은 Kevin MacLeod의 Windswept, CC BY 4.0입니다. 곡명, 작가, 출처, 라이선스 링크, 변경 사항은 리뷰 페이지 하단과 `credits.html`에 표시합니다. 이 라이선스는 음악에만 해당합니다. 자막 글꼴은 네이버 마루 부리와 나눔바른고딕, SIL OFL 1.1이며 글꼴 파일은 배포하지 않습니다. 원문은 `licenses/`에 있습니다. 예전 영상 파일은 `media/`에 남아 있습니다.

## 공개하지 않는 것

원본 설문 CSV, 응답자 식별자, 연락처, 인증 정보는 넣지 않습니다. 등장 나이·성별·견종은 가상 캐스팅이며 화면의 **재구성·AI 생성** 표기가 그 뜻을 같이 보여 줍니다. 준비 과정의 로컬 절대 경로는 사이트에 포함하지 않았습니다.

영상은 Git LFS가 아닌 일반 파일이고, 편당 15MB 미만입니다.

## GitHub Pages에 올리는 남은 단계

이 저장소는 현재 공개 저장소입니다. Pages를 켜면 영상도 `https://sung-park.github.io/sirius-video-review/`에서 열립니다. 아래는 아직 하지 않았습니다.

1. 이 브랜치의 pull request를 `main`에 병합합니다.
2. 저장소 Settings → Pages → Build and deployment → Source를 **GitHub Actions**로 선택합니다.
3. `main`에 올라간 워크플로 **Deploy GitHub Pages**가 끝나면 위 주소로 엽니다.

가시성 변경, pull request 병합, Pages 활성화는 이 작업에서 하지 않습니다.
